Maths for XGBOOST(Optional)

Boosting is an additive modelling process

y_pred=f1(xi)+f2(xi)+...

We have to make ypred close to y

but first gradient boosting loss fn:

Gradient Booost->very flexible loss function
denoted by L(yi,y_pred)

XGboost loss:

L=Gradient Boost loss+ regularization loss(only on the last tree)

Regularization Loss=Ω(f)=gammae*(number of leaf nodes)+lambda*(leaf node value)

penalize tree for making too many leaf nodes and assigning too  much weight to a leaf


XGBoost Objective = Loss + Regularization

L = Σ l(y_i, ŷ_i) + Ω(f)

Ω(f) = γT + (λ/2)Σ(w_j²)

Therefore:

L = Σ l(y_i, ŷ_i) + γT + (λ/2)Σ(w_j²)

t->stage t
L^(t) = Σ l(y_i, ŷ_i^(t-1) + f_t(x_i)) + Ω(f_t)
y_i^(t-1)= pred at stage t-1

Ω(f_t) = γT + (λ/2)Σ(w_j²)

now if we want to find derivate of loss with then first things first u need to now that f_t(x_i_ is non differentiable ,since its just a decision tree ,and decision tree  decision boundaries are non differentiable.How can we smoothen it  , use Taylor Series expansion

f(x)=l(y_i, ŷ_i^(t-1)+ f_t(x_i))
